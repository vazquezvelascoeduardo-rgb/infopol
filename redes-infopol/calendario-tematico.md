# 📚 Calendario temático InfoPol — Lista priorizada de contenido

Este archivo es la **cola de temas** que el agente usará cuando una fila del Excel tenga el tipo de contenido pero el campo "Tema" vacío. El agente irá cogiendo el próximo tema NO USADO de cada bloque.

**Cómo añadir/reordenar temas**: simplemente edita este archivo. Los temas se procesan de arriba hacia abajo en cada bloque.

## ⚠️ NOTAS PARA EDU

1. **Rellena o reordena** los temas según prioridad. El agente coge de arriba abajo.
2. **Añade temas** propios de tu academia que quieras destacar.
3. Si un tema NO debe usarse nunca, **bórralo** de la lista.
4. Para temas muy importantes, puedes **forzar la fecha** poniéndolo directamente en el Excel calendario con el campo "Tema" rellenado.
5. El agente respeta este orden, pero si tú metes algo en el Excel, eso tiene prioridad sobre esta lista.
